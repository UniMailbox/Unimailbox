# Architectural Decision Records

ADRs capture decisions with long-term architectural significance.

Each ADR follows the template:

# ADR-NNN: Title

## Status

Proposed | Accepted | Deprecated | Superseded by ADR-MMM

## Context

Problem and constraints.

## Decision

Chosen solution.

## Alternatives Considered

Meaningful alternatives and why they lost.

## Consequences

Positive and negative consequences. Updates to `docs/architecture/` or
`docs/operations/` are mentioned here.
